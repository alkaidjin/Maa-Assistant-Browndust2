| 项 | Daily | Weekly |

### 失败根因（两条独立叠加，任一条都足以让备份归零）

**① 脚本路径搬家了，任务参数没跟着搬。**

任务里写死的 `-File` 是：

```
F:\MABd2v26.09.5\tools\backup_maintainer.ps1      ← 这个路径今天不存在
```

2026-09-30 的根目录瘦身（commit `ac80b2b`）把它搬到了 `data/maintainer/tools/`。
`powershell.exe -File <不存在的路径>` 会直接以非 0 退出，
任务历史里留下的是"成功启动、脚本没跑"的空档 —— **不报错、不弹窗、什么都不产出**。

> 这就是静默失效的典型：**定时任务没有"路径还在不在"的自检**。
> 凡是靠计划任务托管的脚本，搬目录那天必须回去改任务参数。

**② `-OutDir` 参数疑似编码问题，备份路径存疑。**

`Get-ScheduledTask` / `Get-ScheduledTaskInfo` 读出来的参数是 `E:\¿ä¿Ë±¸·Ý` ——
看着像「夸克备份」的 UTF-8 字节被按 GBK 解读。而注销前导出的任务 XML 是 **UTF-16**，
里面写的其实是正确的 `E:\夸克备份`。

> 所以这一条**降级为「待查」而非「已确证」**：乱码究竟是任务里真存了坏字节，
> 还是控制台输出链路的显示问题，本次没有进一步区分。
> 可以确认的是：不管哪种，`E:\` 下**没有**「夸克备份」目录（实测只有
> `2013 / 归档 / 文档 / 桌面 / rqxy / TRAE`），所以即便脚本成功跑到写文件那一步，产物也落不出去。
>
> 同名变量 `MABD2_BACKUP_DIR` 在 `HKCU\Environment` 里读出来同样是乱码形态。
>
> 教训仍然成立：**路径里不要有中文**。中文路径要穿过「shell → 宽字符 API → 任务 XML」
> 这条链，中途任何一环按 ANSI 编码都可能出问题，而且**注册时不报错、运行时不提示**。
> 要用中文目录就走纯 ASCII 别名或 8.3 短名。

**③ 载体已下线。** 夸克客户端取消开机自启，而这套方案的**上传环节本来就靠夸克客户端自动同步**
（脚本自己不联网，见下），等于备份链的最后一环也没了。

## 二、当初的设计（值得复用的部分）

即使退役了，这套方案的**思路**仍然是对的，值得记下来：

- **用 Task Scheduler 而非应用内调度**：备份不该依赖另一个程序开着。计划任务在什么都没开时也照跑。
- **上传与生成解耦**：脚本只管往一个文件夹写带时间戳的目录，**从不碰任何凭证**；
  云端由客户端自己同步新目录。改同步方案（NAS / 同步盘）不用改脚本一行。
- **轻/重分档**：`local`（仅 config + .workbuddy + 临时校验工具，约 1 MB，秒级）
  与 `full`（+ git bundle + MaaBd2.exe + OCR 模型）分开跑分开保留，
  避免 6 天的小备份把大备份挤出保留窗口。
- **产物分三个 zip + 一份 README-restore.txt**：bundle 可独立 clone，runtime/local 叠在 clone 上即完整。
- **OutDir 硬性拒绝落在项目内**：打包器 `os.walk` 扫全工作区，备份落进去会被扫进用户包。脚本主动 `exit 1` 拦住。
- **保留策略只删自己建的**：`^(full|local)-\d{8}-\d{6}$` 严格匹配，人手放的目录绝不被清。
- **静默 + 低优先级**（Priority 5、Hidden、IgnoreNew、允许电池供电），
  07:00 与游戏脚本抢机器时主动让路；两个任务错开 30 分钟，避免 `IgnoreNew` 把后一个吞掉。

## 三、要复活的话，先按这份清单体检

1. **路径纯 ASCII**，任务参数里 `Get-Content` 出来不是乱码才叫对。
2. 改完路径**当场手跑一次** `powershell.exe -NoProfile -File <脚本> -WhatIf`（或加个 `-DryRun`），
   别靠"等明天早上看有没有产物"验证。
3. 设一个**看门狗**：在 `retired_files.json` 之外，另记一条"备份产物目录的最后修改时间"，
   超过 2 天没变就报警。静默失效的方案必须有静默失效的探测。
4. 保留窗口与频率要对齐（轻档每天 10 份 = 10 天，重档每周 6 份 = 6 周），各自算各自的。
5. 停用时记得**四处一起清**（这次的完整清单）：
   - 计划任务（`Unregister-ScheduledTask`）
   - `HKCU\Environment` 里的路径变量
   - 脚本本体 + 打包器 `EXCLUDE_FILES` 里的护栏条目
   - `README.md` 的目录表
6. 停用后确认磁盘上确实有历史备份；**没有的话这次是止损不是清理**，别误以为"备份一直都在"。

### 附：被删任务的原始定义（注销前 Export-ScheduledTask 留档）

Daily（Weekly 只差 `StartBoundary` = `2026-09-20T07:30:00+08:00`、`-Keep 6`、
去掉 `-NoBundle -NoRuntime`、Description 改 full run）：

```xml
<Task version="1.3" xmlns="http://schemas.microsoft.com/windows/2004/02/mit/task">
  <RegistrationInfo>
    <Description>BD2MAA maintainer backup: local-only state (fast daily run)</Description>
    <URI>\MABd2-Backup-Daily</URI>
  </RegistrationInfo>
  <Principals>
    <Principal id="Author">
      <UserId>S-1-5-21-748471447-3611755521-2984777536-1001</UserId>
      <LogonType>InteractiveToken</LogonType>
    </Principal>
  </Principals>
  <Settings>
    <DisallowStartIfOnBatteries>false</DisallowStartIfOnBatteries>
    <StopIfGoingOnBatteries>false</StopIfGoingOnBatteries>
    <ExecutionTimeLimit>PT45M</ExecutionTimeLimit>
    <MultipleInstancesPolicy>IgnoreNew</MultipleInstancesPolicy>
    <Priority>5</Priority>
    <StartWhenAvailable>true</StartWhenAvailable>
    <IdleSettings>
      <Duration>PT10M</Duration>
      <WaitTimeout>PT1H</WaitTimeout>
      <StopOnIdleEnd>true</StopOnIdleEnd>
      <RestartOnIdle>false</RestartOnIdle>
    </IdleSettings>
    <UseUnifiedSchedulingEngine>true</UseUnifiedSchedulingEngine>
  </Settings>
  <Triggers>
    <CalendarTrigger>
      <StartBoundary>2026-09-20T07:00:00+08:00</StartBoundary>
      <ScheduleByDay><DaysInterval>1</DaysInterval></ScheduleByDay>
    </CalendarTrigger>
  </Triggers>
  <Actions Context="Author">
    <Exec>
      <Command>powershell.exe</Command>
      <Arguments>-NoProfile -NonInteractive -WindowStyle Hidden -ExecutionPolicy Bypass -File "F:\MABd2v26.09.5\tools\backup_maintainer.ps1" -OutDir "E:\夸克备份" -NoBundle -NoRuntime -Keep 10</Arguments>
      <WorkingDirectory>F:\MABd2v26.09.5</WorkingDirectory>
    </Exec>
  </Actions>
</Task>
```

> ⚠️ 注意 `Arguments` 里的 `-File` 路径是**搬家前**的 `tools\`，这正是根因①的铁证。
> `InteractiveToken` = 仅在用户已登录时运行（所以「什么都没开时也跑」那句设计意图其实没完全达成）。
